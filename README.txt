MD HASNAIN — DATA ANALYST PORTFOLIO

HOW TO OPEN
1. Extract the ZIP folder.
2. Open the folder in Visual Studio Code.
3. Double-click index.html, or use the VS Code Live Server extension.
4. The website uses style.css for styling and script.js for the mobile menu.

BEFORE PUBLISHING
- Confirm the name and education details.
- Add your actual LinkedIn profile URL.
- Add your email address if you want it public.
- Add your resume PDF and update the page with its link.
- Replace general project links with exact repositories and add verified dashboard screenshots/results.
- Project descriptions are written from the details currently available; update them if any project scope differs.

PUBLISHING
You can publish the folder with GitHub Pages. Create a repository, upload these files to the repository root, then open Settings > Pages and select the main branch and root folder.
